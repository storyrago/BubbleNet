# Bubble Arcade · Java Swing

> **UI·재생 속도 업데이트:** 800×600 화면, 40px 타일, 다운로드한 파란 경기 프레임, 오른쪽 타이머·8칸 참가자 패널·아이템 슬롯과 대기실 UI를 적용했습니다. 실제 참가자는 4명입니다. 걷기는 프레임당 60ms, 풍선은 200ms, 아이템은 400ms로 재생합니다. 풍선이 3배 빠르게 재생되던 시간 계산을 수정했고 일시정지 시 경기 애니메이션도 정지합니다. [적용 기준과 차이](docs/CLASSIC_UI.md). 최신 화면은 `build/classic-previews/`입니다.

> **도트 적용 업데이트:** 현재 버전은 웹에서 다운로드한 배찌·로두마니 인게임 스프라이트(각 4방향×6프레임), 물풍선, 감금 물방울, 빌리지 타일을 사용합니다. 최신 자산 목록과 출처는 [자산 기록](assets/ATTRIBUTION.md)을 확인하세요. 다오는 아직 포함하지 않습니다. 캐릭터 선택은 2종이며 참가자는 기존대로 4명입니다.

도트 버전 화면: `build/pixel-previews/`. 원본 PNG: `assets/original/`. 개별 크롭 48장: `assets/cropped/`. `sh run.sh --crop-sprites assets/cropped`로 크롭을 재생성할 수 있습니다. PNG는 JAR에도 포함되므로 추가 다운로드가 필요 없습니다.

크레이지 아케이드의 물풍선 대전 규칙을 참고한 **오프라인 Java Swing 팬 프로젝트**입니다. 다운로드한 인게임 도트 자산을 포함하며 실행 시 서버·외부 라이브러리·추가 다운로드가 필요 없습니다. 원작 클라이언트 전체의 복제본은 아닙니다.

## 실행

JDK 17 이상을 설치한 뒤 프로젝트 폴더에서:

```sh
sh run.sh
```

실행용 JAR 생성 및 실행:

```sh
sh build.sh
java -jar build/bubble-arcade.jar
```

Windows에서는 터미널에서 다음 명령을 사용하거나 IntelliJ IDEA에서 `src/main/java`를 Sources Root로 지정하고 `arcade.Main`을 실행합니다.

```bat
mkdir build\classes
javac -encoding UTF-8 --release 17 -d build\classes src\main\java\arcade\*.java
java -cp build\classes arcade.Main
```

## 플레이

로비에서 캐릭터, 게임 모드, 맵 테마를 선택한 뒤 시작합니다. 3초 카운트다운 후 3분 동안 대전합니다.

| 기능 | 1P | 2P |
|---|---|---|
| 이동 | 방향키 | WASD |
| 물풍선 | Space | F |
| 바늘 탈출 | N | G |

- Enter: 시작 / 결과 화면에서 재경기 / 일시정지 해제
- Esc: 일시정지 / 재개. 도움말이 열려 있으면 도움말을 닫습니다.
- H: 도움말. 경기 중 열면 일시정지되며, 닫은 후 Enter로 재개합니다.
- M: 효과음 켜기/끄기
- 창이 포커스를 잃으면 입력을 비우고 경기를 일시정지합니다.

### 모드

- 혼자 놀기: 플레이어 1명 + AI 3명, 개인전.
- 둘이 대결: 같은 키보드의 플레이어 2명 + AI 2명, 개인전.
- 함께 구출: 플레이어 2명 vs AI 2명, 팀전. 팀원이 갇힌 플레이어에게 닿으면 구출합니다.

### 규칙과 기능

- 15×13 격자, 무작위 상자 배치, 스폰 주변 안전 공간.
- 2.4초 지연 물풍선, 십자 물줄기, 연쇄 폭발, 벽 차단과 상자 파괴.
- 물줄기를 맞으면 6초 감금. 바늘 또는 팀원 접촉으로 탈출. 적 접촉/시간 만료 시 탈락.
- 바늘은 시작 시 1개. 탈출 후 1.2초 보호.
- 물풍선 수·물줄기 길이·속도·바늘 아이템.
- 아이템도 인게임 도트 적용: 물풍선·물약·롤러스케이트는 3프레임, 바늘은 인게임 아이템 창 크롭. 맵 드랍/보유 슬롯에 동일 적용. 출처와 크롭 좌표는 `assets/items-provenance.json`.
- 배찌·로두마니 2종의 도트 캐릭터와 빌리지/포레스트/캔디 테마. 참가자는 4명이며 캐릭터가 중복될 수 있습니다. 원작의 특정 맵 배치를 재현하지 않습니다.
- 걷기, 방향 전환, 풍선 맥동, 감금, 파편, 물줄기, 탈출 깜박임 애니메이션.
- 공개 저장소에서 받은 효과음 11개와 30초 반복 BGM. 설치/폭발/획득/감금/구출/탈락/시작/승패/클릭에 연결. M 또는 소리 버튼으로 전체 음소거.
- AI의 폭발 예상, 연쇄 반응 시간 반영, 안전 경로 탐색, 아이템 수집, 블록 파괴, 구출/적 추적.
- 승패/무승부, 재경기, 도움말, 화면 크기 비례 조정, WAV 효과음과 BGM.

## 자료와 그래픽

[조사 및 설계 기록](docs/RESEARCH.md)에 웹 출처, 관찰 내용, 게임에 적용한 결정, 원작과의 차이를 정리했습니다. [자산 목록](assets/ATTRIBUTION.md)에 캐릭터 원화·스프라이트·배포 가능 자산의 검색 결과와 실제 포함 여부를 기록했습니다.

터미널 다운로드 실패 후 GitHub 연결로 실제 도트 PNG를 확보했습니다. `Sprites.java`가 원본 시트를 픽셀 변경 없이 크롭하고 nearest-neighbor 방식으로 표시합니다. 원본 출처·프레임 규격·권리 정보는 `assets/ATTRIBUTION.md`, 파일별 Git blob SHA는 `assets/provenance.json`에 기록했습니다.

## 개발과 검증

```sh
sh test.sh
sh run.sh --render build/previews
sh run.sh --export-art assets
sh run.sh --crop-items assets/cropped-items
```

`--render`는 창 없이 실제 Swing 패널로 로비/경기/감금/결과 PNG를 생성합니다. `--export-art`는 투명 배경 캐릭터 시트를 생성합니다.

| 파일 | 책임 |
|---|---|
| `Game.java` | UI와 분리한 게임 상태, 충돌, 폭발, 아이템, AI, 승패 |
| `Main.java` | Swing 창, 키 바인딩, 60Hz 고정 업데이트, 화면과 메뉴 |
| `Art.java` | UI, 자체 테마, 스프라이트 렌더러 연결 |
| `Sprites.java` | 다운로드 PNG 로딩·크롭·방향 매핑·도트 애니메이션 |
| `Sound.java` | WAV 디코딩, 효과음 동시 재생, BGM 반복/일시정지/음소거, 출력 장치 오류 처리 |
| `GameTest.java` | 규칙 회귀 검증, 12개 시드 전체 경기, UI 입력 전이 |

JDK 26에서 Java 17 타깃 컴파일 및 헤드리스 테스트/PNG 렌더링을 검증했습니다. 현재 작업 환경에서는 네이티브 AWT 창 실행이 `Abort trap: 6`으로 종료되어 **실제 창에서의 키보드·마우스 조작 및 오디오 청취는 미검증**입니다. 일반 데스크톱 세션에서 `sh run.sh`로 실행해야 합니다.

현재 범위에 온라인 소켓 대전, 계정/상점, 원작의 탈것·특수 맵·랭크 시스템은 포함하지 않습니다. 이동은 격자 판정 + 부드러운 화면 보간 방식이므로 원작의 픽셀 단위 모서리 통과 판정과 다릅니다.

오디오 파일 검증은 `sh run.sh --check-audio`, 실제 로컬 장치 재생 점검은 `sh run.sh --audio-smoke`로 실행합니다. 현재 도구 환경에서는 오디오 출력 장치를 찾지 못했으므로 실청취는 미검증입니다. 오디오 장치가 없으면 로그와 “소리 없음” 상태를 표시하고 게임은 계속 실행됩니다. 음원은 JAR에 포함돼 오프라인 실행됩니다.
