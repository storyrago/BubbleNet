## 2. 게임 루프 분석

맵의 상자는 이동을 제한하면서 아이템을 숨깁니다. 초반에는 상자를 제거해 능력치를 키우고, 중반에는 열린 길에서 물풍선의 십자 범위와 설치 수로 상대의 이동을 제한합니다. 물줄기에 닿았다고 즉시 끝나지 않고 감금 상태가 생기므로, 바늘 보유와 팀원의 구출이 전투 결과에 영향을 줍니다.

구현 상태 전이:

```text
로비 → 3초 준비 → 경기 → 결과 → 재경기 / 로비
                    ↕
                  일시정지

생존 ──물줄기──> 감금 ──바늘/아군 접촉──> 생존 + 보호
                  └──적 접촉/시간 만료──> 탈락
```

물풍선과 블록 판정 순서:

1. 설치 칸에 기존 풍선이 없고 소유자의 설치 수 제한 이내인지 검사.
2. 설치 직후 해당 칸을 벗어날 수 있지만 다시 들어올 수 없음.
3. 폭발 시 상하좌우로 사정거리만큼 진행. 고정 벽 앞에서는 중단.
4. 파괴 상자는 부수되 해당 방향 물줄기는 그 칸에서 중단.
5. 다른 풍선을 만나면 연쇄 폭발. 자신을 목록에서 먼저 제거해 재귀 순환 방지.
6. 물줄기 칸의 플레이어를 감금. 파괴 후 생성된 아이템은 해당 칸의 물줄기가 사라져야 수집 가능.

## 4. UI 분석과 적용

원작 참고 화면의 핵심은 플레이 필드를 가장 넓게 두고 참가자와 아이템 상태를 별도 영역에 유지하는 것입니다. 구현은 1200×850 논리 해상도에서 720×624 필드, 우측 참가자 카드, 상단 타이머, 하단 조작 안내로 구성합니다. 창 크기가 바뀌면 종횡비를 유지하고 마우스 좌표도 같은 변환으로 처리합니다.

로비는 캐릭터 4장의 선택 카드와 모드/테마 설정을 한 화면에서 보여줍니다. 원작의 온라인 방 목록과 채팅은 로컬 게임에 맞춰 생략했습니다. 게임 화면의 이벤트 기록은 실제 구출/감금/탈락 정보이며 네트워크 채팅을 흉내내지 않습니다.

판독성을 위해 플레이어 색, 1P/2P/AI 표시, 상태 텍스트, 감금 제한 게이지를 함께 사용합니다. 원작의 로고·계급·상점 UI 원본은 포함하지 않습니다.

## 5. 캐릭터·모델·애니메이션 조사

다오/배찌 계열 원화에서 큰 머리와 작은 몸의 비율, 전신 색 구분, 둥근 외곽선, 얼굴 중심 표현을 관찰했습니다. 모바일판의 3D 렌더 이미지는 질감 참고로만 분리했습니다. Swing은 2D 렌더러이므로 3D 모델 런타임 대신 Java2D 도형과 그라데이션으로 구현했습니다.

실제 포함한 캐릭터는 루비트/모모/클로버/루나 4종의 자체 디자인입니다. 원작 캐릭터 이름이나 정확한 능력치를 복제했다고 주장하지 않습니다. 캐릭터 색 외에도 지느러미·둥근 귀·잎·별로 실루엣을 구분합니다.

| 상태 | 표현 | 시간 기준 |
|---|---|---|
| 정지 | 기본 방향별 모습 | 고정 |
| 걷기 | 발 교대, 팔 교대, 몸 상하 이동 | 실제 이동 중 walk 위상 증가 |
| 방향 | 아래/왼쪽/오른쪽/등 모습 | 입력 방향 |
| 물풍선 | 세로/가로 맥동, 하이라이트, 남은 시간 바 | 경과 시간/퓨즈 |
| 감금 | 반투명 구형 외곽, 얼굴 표정 변화, 부유 | 감금 상태/애니메이션 시계 |
| 탈출 보호 | 주기적 깜박임 | 보호 타이머 |
| 블록 파괴 | 파편 속도와 중력 | 시뮬레이션 dt |
| 탈락 | 납작한 색상 잔상 | OUT 상태 |

`characters.png`는 96×96 칸, 6열×16행입니다. 각 캐릭터마다 아래/왼쪽/오른쪽/위 4행, 각 행 6프레임입니다. `trapped.png`는 6열×4행입니다. 이 PNG들은 원작 시트가 아니라 같은 Java2D 그림의 내보내기 결과입니다.

## 6. 구조와 AI

규칙 엔진에는 Swing 참조가 없습니다. 시드는 생성자에서 주입하고, 동일 시드/입력/시간 간격이면 동일한 게임을 재현할 수 있습니다. 화면 업데이트는 EDT에서 고정 1/60초 단위로 수행하고 각 프레임의 실제 지연은 0.1초로 제한합니다. 효과음은 별도 데몬 스레드의 제한된 큐에서 생성합니다.

AI는 풍선별 물줄기 범위와 예정 폭발 시간을 만든 뒤, 연쇄 반응으로 앞당겨지는 시간을 반복 전파합니다. 위험한 칸에서는 BFS로 안전 칸을 찾습니다. 공격 전에 가상의 물풍선을 놓아 탈출 경로를 검사합니다. 평상시에는 아이템, 인접 상자, 적/감금 플레이어 거리로 목적지를 평가합니다.

이는 시간축 전체를 탐색하는 완전한 최적 AI는 아닙니다. 미래에 파괴될 상자, 이동 중 상대의 추가 설치, 동시 물줄기의 모든 전술을 예측하지 않습니다. 원작 실력자 수준의 AI나 네트워크 동기화 구현으로 소개하지 않습니다.

## 7. 검증과 남은 범위

자동 검증: 벽/상자/경계 충돌, 설치 용량, 설치 칸 탈출 및 재진입 차단, 폭발 차단/상자 제거/연쇄 반응, 감금/바늘/무적/시간 만료, 아군 구출/적 탈락, 아이템과 상한, 일시정지, 개인전/팀전 승리와 무승부, 12개 시드 전체 경기, UI 키 전이.

실제 Swing 패널의 로비/경기/감금/결과 화면을 PNG로 렌더링했습니다. 네이티브 창은 실행 환경의 `Abort trap: 6` 때문에 실사용 입력 검증을 하지 못했습니다. 화면 캡처를 실제 키보드 플레이 성공으로 간주하지 않습니다.

미구현: TCP/UDP 멀티플레이, 로그인, 매칭, 상점, 저장된 전적, 원작 맵의 정확한 배치, 픽셀 단위 이동 보정, 탈것, 발차기/던지기, 몬스터 모드, 원작 사운드/스프라이트. 이번 결과는 핵심 규칙을 구현한 로컬 게임이며 원작 전체의 동일 복제본이 아닙니다.
