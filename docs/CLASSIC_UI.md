# 경기 UI 및 애니메이션 조정

## 자료

- 넥슨 게시판 대기실 이미지: https://ca.nexon.com/Free/Content/118939?page=1&selectType=All — 파란 패널, 8칸 슬롯, 오른쪽 맵 선택, 하단 시작 버튼 배치를 참고했습니다.
- 경기 프레임 PNG: https://github.com/NPpj/CrazyArcade/blob/master/GameClient/src/assets/game/GameBackGround.png — 다운로드한 1020×930 이미지 전체를 800×600에 맞춰 표시합니다. 비율 변환이 있으므로 원작 화면의 픽셀 단위 일치가 아닙니다.
- 걷기 참고: https://github.com/visolleon/bnb/blob/gh-pages/bnbRole.js — 6프레임, 60ms 간격.
- 풍선 참고: https://github.com/visolleon/bnb/blob/gh-pages/bnbPaopao.js — 3프레임, 200ms 간격.
- 아이템 참고: https://github.com/visolleon/bnb/blob/gh-pages/bnbBarrier.js — 3프레임, 400ms 간격과 100ms 단위 상하 움직임.

공개 재현 프로젝트의 값이며 넥슨 원작 엔진에서 측정한 값은 아닙니다.

## 적용

- 논리 해상도 800×600, 경기장 600×520, 타일 40×40. 창 확대 시 좌표와 마우스 입력을 같은 비율로 변환합니다.
- 캐릭터는 기본 배율 1로 원본 도트를 표시합니다. 이동 중 60ms마다 다음 프레임, 정지 시 첫 프레임을 표시합니다.
- 풍선은 설치 후 경과 시간만 사용합니다. 기존에는 전역 시간에 설치 후 시간의 2배를 더하여 실제로 15fps로 재생되는 오류가 있었습니다. 현재는 5fps입니다.
- 아이템은 2.5fps와 100ms 계단식 상하 이동을 사용합니다.
- 경기 애니메이션 시간은 플레이 중에만 흐릅니다. 로비 애니메이션은 별도 시간을 사용합니다.
- 경기 프레임에 맞춰 오른쪽 타이머, 참가자 8칸(4명+빈칸), 바늘 보유량, 소리·도움말·나가기 버튼을 배치했습니다.
- 대기실·도움말·일시정지·결과 창도 작은 파란 패널로 변경했습니다. 대기실은 직접 그린 UI이며 원작 이미지 전체 복제는 아닙니다.

## 검증과 남은 차이

Java 17 타깃 컴파일, 12개 시드 전체 경기와 UI 입력 전이 테스트, 헤드리스 PNG 렌더링으로 확인했습니다. 실행 JAR에도 새 프레임 PNG가 포함됩니다. 현재 환경에서 네이티브 창 실조작과 체감 속도 비교는 검증하지 못했습니다.

풍선 폭발 지연 2.4초, 감금 6초, 이동 속도와 격자 충돌은 기존 게임 규칙을 유지합니다. 공개 참고 코드의 풍선 지연은 3초로 서로 다릅니다. 원작 이동의 모서리 통과, 전체 캐릭터, 실제 맵 배치, 모든 특수 효과·폰트·로비 기능까지 동일하게 구현된 상태는 아닙니다.
